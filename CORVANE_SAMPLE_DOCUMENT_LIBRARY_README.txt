TIB SYSTEMS LLC — CORVANE SAMPLE DOCUMENT LIBRARY

Purpose
This package gives Controls Lead trainees realistic fictitious client documents showing what common controls-project inputs and workpapers can look like.

How to use
1. Read the fieldwork narration.
2. Open the relevant Corvane sample.
3. Compare it with the authoritative/public real-world reference in 00_REAL_WORLD_SOURCE_MAP.xlsx.
4. Identify the people, systems, processes, risks, controls, evidence and open questions.
5. Use those facts to populate the TIB controls workbooks.

Important
The Corvane files are original fictitious training samples. They are not copied client documents.
External references are provided as links for education and comparison.
